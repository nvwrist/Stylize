# Stylize

Лёгкий одностраничный 3D-редактор для телефона: собрать модель, вылепить, раскрасить текстуру и выгрузить `.glb` для three.js.

Четыре режима внизу:

- **Сборка** — лёгкие фигуры (куб, крыша, пирамида, цилиндр, конус, шар, тор, плоскость) появляются там, куда смотрит камера, и встают на землю (сетка пола, метры). Гизмо двигает, вращает и масштабирует с привязкой 0,25 м / 15°; размер, позицию и поворот можно ввести цифрами. «Дубль», «Зеркало» (копия через ось X, для колёс и окон), «На землю», виды камеры (спереди, сверху, справа). Шаблоны «Дом» и «Машина» собраны из этих фигур; кнопка «?» показывает подсказку по вкладке.
- **Лепка** — кисти: тянуть, сглаживать, раздувать, хват, плоскость, сжать. Размер и сила, «Вдавить», симметрия по X, детализация ×4. Вершины на UV-швах сварены, поэтому трещин нет.
- **Сетка** — редактор полигонов: выбор полигонов (два копланарных треугольника считаются одним четырёхугольником) и вершин касанием, двигать/вращать/масштабировать выбранное, выдавить, удалить, создать грань по вершинам, слить вершины, перевернуть нормали. «Авто-развёртка UV» заново раскладывает объект на острова (по нормалям, с одинаковой плотностью текселей) и переносит уже нарисованное на новую развёртку; окно «UV» показывает развёртку поверх текстуры.
- **Краска** — кисть, ластик, заливка по текстуре детали (UV-развёртка сохраняется, у фигур она без наложения островков). Режим **«Фото»**: снимок лежит поверх сцены, его двигают пальцем и подгоняют ползунками (масштаб, поворот, прозрачность превью, сила), а «Запечь» проецирует его из текущей камеры на текстуру выбранного объекта или всей сцены. Закрытые от камеры и скользящие под острым углом участки не закрашиваются, запекание отменяется кнопкой ↶.

Кнопка «Каркас» в углу сцены показывает рёбра поверх модели; сверху видно число вершин, рёбер и треугольников объекта или всей сцены.

Общая отмена и возврат (↶ ↷, Ctrl+Z / Ctrl+Shift+Z) работают для лепки, краски и сборки.

Один палец рисует или лепит, два пальца вращают и приближают. На компьютере: левая кнопка рисует, правая вращает, колесо приближает, Shift — «Вдавить».

Открывает `.glb` (без сжатия Draco/Meshopt). Сохраняет `.glb` (внутри `.zip`) с выбором размера текстур 256/512/1024/как есть и формата PNG/JPG, а также текстуры в PNG.

Запуск: открыть `index.html` в браузере. Three.js подключается с cdn.jsdelivr.net, нужен интернет.
