# Stylize

Лёгкий одностраничный 3D-редактор для телефона: собрать модель, вылепить, раскрасить текстуру и выгрузить `.glb` для three.js.

Четыре режима внизу:

- **Сборка** — фигуры (куб, шар, цилиндр, конус, тор, плоскость) и шаблоны, выбор касанием, двигать/вращать/масштабировать, дубль, удаление.
- **Лепка** — кисти: тянуть, сглаживать, раздувать, хват, плоскость, сжать. Размер и сила, «Вдавить», симметрия по X, детализация ×4. Вершины на UV-швах сварены, поэтому трещин нет.
- **Сетка** — редактор полигонов: выбор граней и вершин касанием, двигать/вращать/масштабировать выбранное, выдавить, удалить, создать грань по вершинам, слить вершины, перевернуть нормали. «Авто-развёртка UV» заново раскладывает объект на острова (по нормалям, с одинаковой плотностью текселей) и переносит уже нарисованное на новую развёртку; окно «UV» показывает развёртку поверх текстуры.
- **Краска** — кисть, ластик, заливка по текстуре детали (UV-развёртка сохраняется, у фигур она без наложения островков).

Кнопка «Каркас» в углу сцены показывает рёбра поверх модели; сверху видно число вершин, рёбер и треугольников объекта или всей сцены.

Общая отмена и возврат (↶ ↷, Ctrl+Z / Ctrl+Shift+Z) работают для лепки, краски и сборки.

Один палец рисует или лепит, два пальца вращают и приближают. На компьютере: левая кнопка рисует, правая вращает, колесо приближает, Shift — «Вдавить».

Открывает `.glb` (без сжатия Draco/Meshopt). Сохраняет `.glb` (внутри `.zip`) с выбором размера текстур 256/512/1024/как есть и формата PNG/JPG, а также текстуры в PNG.

Запуск: открыть `index.html` в браузере. Three.js подключается с cdn.jsdelivr.net, нужен интернет.
