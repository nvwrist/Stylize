# Stylize

Одностраничный редактор для раскраски текстур GLB-моделей с телефона.

- Открывает `.glb` (без сжатия Draco/Meshopt) или берёт одну из встроенных моделей.
- Кисть, ластик, заливка, отмена, палитра, размер кисти.
- Один палец красит, два пальца вращают и приближают.
- Сохраняет модель (`.glb`, внутри `.zip`) и текстуры (`.png`).

Запуск: открыть `index.html` в браузере. Three.js подключается с cdn.jsdelivr.net, нужен интернет.
